# TS Music Desk 1.2.1

为 TeamSpeak 频道提供 **网易云音乐** 搜索、点播、歌单和网页共享控制的音乐机器人。

项目提供 **Windows 本地版** 和 **Ubuntu 服务器版**。两者共享主要的音乐与歌单功能；运行位置、管理方式、账号登录方式和歌手浏览方式有所不同。音乐通过机器人进入 TS 频道，朋友在主机分发的网页端点歌，在 TeamSpeak 客户端中收听。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 搜索 | 搜索网易云歌曲与相关歌单，支持对已加载歌曲按人气排序。本地版保留歌手资料与歌曲页面；服务器版通过歌手专辑浏览歌曲。 |
| 播放控制 | 播放、暂停、切歌，拖动或输入数值调节音量；支持列表循环、单曲循环、随机播放，以及拖动调整待播放队列。 |
| 保留队列的插播 | 搜索后立即播放某首歌时保留原队列；被打断的歌曲排到下一首，从头播放。 |
| 自建与开放歌单 | 创建、命名、填写简介、添加歌曲、去重、搜索、拖动排序、编辑和删除；可将当前队列保存为歌单。 |
| 用户歌单 | 通过网易云用户昵称或用户 ID 查找用户歌单，导入或播放。 |
| 共享控制 | 分享授权链接，让朋友通过浏览器搜索、点歌和管理开放的自建歌单，并按授权使用相关功能。 |
| 点播署名 | 设置点播 ID，显示歌曲由谁点播，并提供常用昵称选择。 |
| 分享链接分发 | 可在频道加入和分享地址创建、更新等事件发生时发送控制链接。 |
| 当前播放与歌词 | 播放队列支持自动及手动定位当前歌曲；封面下方显示可用歌词并随进度高亮。 |
| 界面缩放 | 提供 100%、125%、150%、175% 缩放，各浏览器分别记住选择。 |
| 资源监控 | 本地管理端显示工具资源占用；服务器管理端和朋友端显示服务器整体负载、内存与网络流量。 |

自建歌单保存在机器人运行端，重启后仍可保留；自建歌单开放给已获相应授权的用户编辑。网易云原始歌单与机器人自建歌单分开管理。

## 本地版部署

适合在自己的 Windows 电脑上运行，通过桌面窗口管理机器人。播放期间需要保持电脑和机器人运行。

### 发行包运行

从本项目 Releases 下载 Windows 安装包（`.exe`）或便携包（`.zip`）。安装包运行后按提示安装；便携包先完整解压，再运行其中的 `TS Music Desk.exe`。发行包与下面的源码启动方式二选一。

### 源码运行：环境准备

- Windows x64，能够连接网易云和目标 TeamSpeak 服务器。
- 下载或克隆完整项目，保留原有目录结构。
- 首次启动需要联网下载缺少的依赖和运行组件；统一入口会准备 Node.js 22，无需提前手动安装。

### 源码运行：启动步骤

1. 双击 **本地版/一键启动.cmd**。
2. 等待 5 秒自动执行，准备依赖、构建当前代码并打开桌面程序。按 **M** 可进入管理菜单，按 **0** 退出入口。
3. 在程序中添加 TS 服务器、频道及所需连接信息。
4. 登录网易云账号，连接机器人，搜索歌曲或选择歌单播放。
5. 需要朋友共同点歌时，在分享控制中创建授权链接，按需开放操作权限。

机器人可自行连接 TS 服务器；运行它不要求本机同时打开 TS 客户端。你和朋友需要在 TS 客户端进入对应频道收听。

本地版的公网分享使用隧道提供外部访问，临时地址可能变化；朋友仍应使用程序生成的完整授权链接。

## 服务器版部署

适合让机器人在 Ubuntu 服务器后台长期运行。部署完成后，自己的电脑可以关机；音乐请求、网页服务和 TS 播放继续由服务器处理。

### 环境准备

- Ubuntu 22.04 x86_64 服务器，具备访问网易云、下载依赖和连接目标 TS 服务器的网络条件。
- 一台用于首次部署和后续管理的 Windows 电脑，启用 Windows OpenSSH 客户端。
- 可以通过 SSH 密钥登录的服务器账号，并具备免密 sudo 权限。
- 已核实的服务器 ED25519 主机指纹，以及本机 SSH 私钥文件路径。

先在自己的终端确认可以登录服务器，例如：

~~~powershell
ssh ubuntu@你的服务器IP
~~~

服务器主机指纹可在已登录的服务器终端查看：

~~~bash
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
~~~

### 首次部署

1. 双击 **服务器版/一键部署.cmd**，等待 5 秒执行，或按 **M** 打开管理菜单。
2. 按提示填写 SSH 地址、端口、已核实的主机指纹和私钥路径。这里只需要文件路径，私钥不复制进项目。
3. 入口自动构建和校验部署包，通过 SSH 上传，安装服务器运行环境及后台服务，并准备网易云官网登录浏览器组件。
4. 保存终端显示的主人控制台登录密码。
5. 部署完成后打开主人控制台，添加 TS 预设、登录网易云并连接机器人。

网易云首次账号登录在部署完成后的主人控制台中进行，不是在 SSH 安装终端中进行。如选择安装官方 TS 客户端，还需要自行阅读并决定是否接受其许可。

### 主人控制台与朋友入口

**主人控制台**默认通过 SSH 转发访问：

~~~text
http://127.0.0.1:18080/admin
~~~

服务器入口按 **M → 打开主人控制台**，可建立管理转发并打开页面。管理页面打不开时，先确认 SSH 转发是否仍在运行；转发关闭不代表服务器机器人已经停止。

**朋友入口**可通过菜单中的“配置固定公网入口”设置。此功能使用 Caddy 提供 HTTPS，需要在云防火墙放行 TCP **80、443**。配置成功后，从主人控制台复制完整邀请链接给朋友使用。

固定网站地址与主人管理入口分开。邀请链接在未撤销时可跨机器人重启继续使用；只发送网站首页地址不能替代完整授权链接。

### 更新与日常管理

- **更新：** 获取新代码后，继续运行 **服务器版/一键部署.cmd**。入口会识别已有安装并应用代码更新，保留歌单、账号、TS 身份、公开地址和当前音频后端。
- **依赖变化：** 小更新发现依赖锁文件不匹配时会在替换前停止，需要处理依赖升级后再继续。
- **管理：** 同一入口的菜单提供控制台、服务状态、重启、固定入口、音频检查、音频链路切换、连接设置和服务器打包。
- **数据：** 保存在服务器安装目录的 **server-data/**；Windows 端部署连接设置保存在 **work/deployment/settings.json**。
- **打包：** 服务器完整包和小更新包输出到 **release/server/**。

部署脚本管理音乐机器人自身服务，不会替你安装或重新配置现有 TS 服务器。本地版与服务器版分别保存自己的运行数据，更新服务器不会自动同步本地版账号和歌单。

## 技术链路

### 界面与任务处理

本地版使用 **Electron + Vue** 提供桌面界面，服务器版使用 **Node.js 后端 + Vue 网页**提供主人控制台和朋友控制页面。

搜索、歌单和账号等网易云请求由音乐任务模块处理；播放内核运行在独立工作线程中，减少界面与检索处理对音频调度的直接干扰。服务器版还提供真实的网易云官网登录浏览器，用于交互登录并保存通过验证的会话。

朋友网页发送的是点歌、暂停、排序等控制指令。音乐音频由机器人运行端获取并传给 TS，不经过朋友的控制网页播放。

### 原有 TS3 协议链路

本地版使用此链路；服务器版首次安装默认使用此链路，后续部署保留服务器已有选择。

~~~text
网易云获取歌曲播放地址
        ↓
机器人运行端拉取音频
        ↓
FFmpeg 解码 → PCM 缓冲 → Opus 编码
        ↓
项目内的 TS3 协议内核发送语音数据
        ↓
TeamSpeak 服务器转发 → 频道内的 TS 客户端收听
~~~

此模式由项目内核负责音频帧调度、编码和语音发送，不要求额外启动官方 TS 客户端。服务器版部署到远程后，这些工作也随之在服务器执行。

### 官方客户端链路（服务器版可选）

通过服务器菜单选择“切换官方音频”启用，由 **SinusBot 桥接官方 TS3 客户端**完成播放与发送。

~~~text
网易云获取歌曲播放地址
        ↓
Music Desk 把播放地址与控制指令交给 SinusBot
        ↓
SinusBot 音频桥接 → 官方 TS3 客户端编码与发送
        ↓
TeamSpeak 服务器转发 → 频道内的 TS 客户端收听
~~~

这里使用的是官方 TS 客户端的语音发送链路，桥接组件由第三方 SinusBot 提供。Music Desk 仍负责界面、网易云账号与歌曲信息、队列、歌单和授权共享。

切换前会存档原有链路，可从同一菜单恢复。官方模式使用独立的客户端身份，可能需要重新设置频道权限；暂停后恢复会还原保存的播放位置，可能出现重新缓冲。只有主动选择切换后才会启用此模式，普通更新不会自动切换。

作者在自己的测试环境中使用官方客户端链路时，听感未达到预期；这是特定环境下的反馈，不代表所有服务器的效果。该链路保留为可选对照方案。

### 音质与诊断范围

网易云音源质量和 TS 频道中的最终音质不是同一个设置。歌曲经过解码和 TS 语音编码后才传给听众，无损音源不代表最终传输无损。

原有链路的诊断可记录缓冲、出帧、编码和发送队列等信息；官方客户端模式由独立组件负责这些步骤，原内核的帧统计不再适用。本机出帧正常也不能单独证明听众已完整收到音频，实际听感仍需结合接收端判断。

## 项目文件与许可

- **src/**：桌面端、网页界面、服务器后端和任务模块。
- **vendor/teamspeak-music-bot-1.13.2/src/**：播放与 TS 协议内核；其中 **src/data/** 也是源码。
- **scripts/**、**deploy/**：构建、部署、更新和维护逻辑。
- **public/**、**resources/**：图标和第三方许可。
- **tests/**：自动化测试。
