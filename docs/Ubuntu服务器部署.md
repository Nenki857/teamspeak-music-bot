# Ubuntu 服务器部署与更新

当前统一操作说明见 [项目 README](../README.md) 和 [服务器版说明](../服务器版/README.md)。

统一入口是 服务器版/一键部署.cmd，首次安装和后续更新自动区分。按 M 打开服务管理、固定地址、音频切换与打包菜单。历史文档中的分散 CMD 已整合，日常不再运行旧入口。

已有安装会复用 Node、FFmpeg、官网登录浏览器、当前音频后端和数据库。更新前核验依赖锁及源码摘要，备份全部被替换的代码目录；更新失败按原实现恢复。依赖变化时会在停止服务或覆盖代码之前拒绝增量升级。

关闭 SSH 转发只影响主人网页入口，不影响 systemd 后台机器人。服务名是 ts-music-desk.service，主人端口 18080，固定朋友入口为独立 HTTPS 服务。

直接在服务器手动安装时，完整服务器发行包仍提供 deploy/preflight.sh、deploy/install-ubuntu.sh 和 deploy/wait-server.sh。不要把首次安装脚本作为已有服务的升级脚本。


## 网易云网页会话与请求诊断

服务器默认使用官网网页会话请求，`TSMD_NETEASE_WEB_CLIENT=1` 可明确启用；设置为 `0` 可显式保留旧请求模式。它只影响网易云请求，不切换 TS 音频后端。

请求按服务器统一排队，遇到 -460、-462 或 429 后短暂冷却 60 秒，不自动重试或重复登录。冷却时长是本项目保护设置，不代表网易云公布的限制时长。登录检查暂时失败会保留保存的会话；明确未登录与检查异常分别处理。

脱敏日志位于运行数据目录的 `logs/netease-requests.jsonl` 与 `logs/netease-sessions.jsonl`，各保留当前文件与上一份轮转文件，单文件约 1 MiB。只记录接口名、返回码、耗时等诊断字段，不记录 Cookie、搜索词、手机号、账号 ID 或歌曲播放地址。

修复程序通过本机服务健康检查只表示机器人后台已运行，不代表网易云一定接受后续请求。应用更新后需由管理员手动验证一次搜索、点击歌手名搜索及播放；不要通过反复登录或自动重试来测试平台限制。


### 按专辑分组的歌手歌曲

服务器版点击歌手名后，自动从专辑中分批整理歌曲。每批按顺序最多读取 3 张专辑，新增约 50 首后停止继续读取专辑，累计最多载入 500 首曲目；点“加载更多歌曲”继续。已载入曲目按专辑分组，使用封面、大标题和边框。组内重复歌曲 ID 去重，同一首歌在不同专辑中的收录分别保留。

时间排序比较已载入专辑的发行日期，组内保留曲序；人气排序用已载入歌曲的接口热度，同组内按热度排序，专辑按组内最高热度排列，缺少热度时保留原顺序。排序只调整已载入内容，不新增请求。“专辑列表”保留卡片视图，并可单独查看某张专辑；已整理的内容可直接复用。

页面切换会停止后续自动读取；请求失败保留此前进度，需用户手动继续，不自动重试。保留“搜索歌手名字”按钮。本功能只调用已验证可用的专辑列表和专辑内容接口，歌手资料与歌手歌曲旧接口继续停用。主人、朋友和自建歌单搜索共用此视图，逐首播放、加队列、加自建歌单继续使用原有权限。本地版仍保留原歌手页面。

### 专辑折叠与歌曲检索

专辑歌曲分组默认收起，点击专辑标题或使用“全部展开/全部收起”查看曲目。分组与单独专辑内不显示重复表头、歌曲序号及专辑列，保留封面、歌名、歌手、时长和原有操作。

专辑页的搜索仅筛选已加载歌曲，可匹配歌名、歌手及专辑名，不发起额外网易云请求。匹配的专辑会自动展开；清空搜索恢复之前的展开状态。暂未找到时可以继续手动加载更多歌曲再筛选。时间与人气排序继续作用于已加载内容。

### 播放队列定位与封面吸顶

进入播放队列页时，页面会在当前播放曲目出现后自动定位一次；离开再返回时再次定位。顶部“定位当前播放”按钮可手动回到当前曲目。标题、操作和左侧封面保持可见，右侧歌曲列表独立滚动，歌曲不会滑入标题下方；窄屏使用紧凑封面和下方滚动列表。浏览期间切歌不会强制改变滚动位置。

定位只读取浏览器已有队列和 DOM，使用本地滚动与 CSS，不增加接口请求、轮询或网易云访问。滚动和布局有少量浏览器开销，不会明显增加服务器负载。

### 直接输入音量

点击播放器右侧的音量百分比可输入 0–100；回车或移出输入框确认，Esc 取消，超出范围自动限制。输入期间状态更新不会覆盖草稿；提交期间显示目标值并防止重复发送，失败恢复服务端音量。仍复用原有音量权限和请求校验，仅在确认时提交一次，不增加轮询。

### 当前播放歌词

播放队列的封面与歌名下方显示当前歌曲歌词，有译文时一起显示。桌面默认展开，手机默认收起；可手动展开或收起。当前行根据已有播放进度在浏览器本地高亮，暂停与调整进度后同步；手动浏览歌词会停止自动跟随，点击“跟随歌词”恢复。显示对齐机器人进度，收听端语音缓冲仍可能带来少量差异。

只通过现有查看权限读取当前网易云歌曲的歌词。服务端直达独立音乐目录线程，不经过音频线程；同曲并发请求合并。数据目录的 cache/lyrics 保存最多 200 首文本歌词，内存最多 32 首；正常结果有效期 30 天，空歌词 1 天，不保存登录字段。缓存文件写入失败不会让已获取的歌词失效。遇到请求失败不自动重试，同一首失败请求本机冷却 60 秒；用户可手动重试，仍遵守现有网易云请求冷却规则。页面隐藏或歌词收起时停止本地高亮计时，没有新增进度轮询。

封面下方和左下角底部播放器的歌手名可点击，跳转至普通搜索并自动搜索该名字；有多位歌手时分别显示入口，仅有合并署名时按完整署名搜索。此入口不调用歌手资料、歌手歌曲或专辑接口，保留原有搜索权限与操作中禁用状态。

### 三种播放模式

模式菜单依次为列表循环、单曲循环、随机播放。列表循环播完末曲回到首曲；单曲循环仅在自然播完时从头重播当前曲，手动上一首、下一首仍可切歌。随机播放沿用已有不重复随机顺序，本轮播完停止。旧顺序播放设置归为列表循环，旧随机循环设置归为随机播放；单曲模式可保存并在重启后恢复。原自定义 TS 链路和官方客户端链路共用队列行为。

### 侧栏服务器负载

服务器版主人端与已授权朋友页左侧显示整机 CPU、已用/总内存、1/5/15 分钟平均系统负载和外部网卡收发速率。内存按总量减 MemAvailable 计算，考虑可回收缓存；系统负载是平均运行或等待资源的任务数，并非 CPU 百分比，旁边显示核心数。网卡统计包含 TS 与其他服务，不代表机器人单独用量或语音送达情况。

服务端按需读取 /proc/stat、/proc/meminfo、/proc/loadavg 与 /proc/net/dev 四份计数，统一缓存 2 秒并合并并发读取，不扫描进程、不执行外部命令；无人查看时无后台资源采样。浏览器每 2 秒读取一次，页面隐藏后暂停，采样故障显示不可用而不显示假零。朋友接口使用已有查看权限、会话、来源与 CSRF 校验，独立限流，不占用音乐 RPC 的操作额度。它不请求网易云，也不进入音频线程。资源采样和每个打开网页的刷新会产生少量额外开销；本地版仍按原方式显示工具全部组件占用。

服务器版侧栏的负载卡片固定在左下方，开放歌单列表占用导航与底部区域之间的全部剩余高度，内容超出时在歌单区域独立滚动。左侧移除重复的在线提示与授权列表，右上角仍可查看在线状态和具体权限；主人管理操作、网易云登录入口保留。窄屏朋友页保持原有横向导航布局。

自建歌单编辑区的“已选歌曲”标题右侧提供“一键清空”，只清空浏览器当前草稿中的选曲，保留名称、简介及原歌单编辑目标。清空后可“撤销清空”；添加新歌曲或切换为另一份编辑草稿后结束本次撤销。此操作不发送服务器修改请求，不改变播放队列；需要按原保存按钮才会写入歌单，空歌单仍不可保存。
