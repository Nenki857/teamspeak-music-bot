# Windows 本地版

请前往 **[GitHub Releases](https://github.com/Nenki857/teamspeak-music-bot/releases)** 下载 **`TS-Music-Bot-版本号-x64.zip`**。

完整解压 ZIP 后，双击其中的 **`TS Music Bot.exe`**。完整包已包含运行依赖、音频组件和公网分享组件，无需安装 Node.js 或 npm。

此目录中的 **下载本地版.cmd** 只会打开 Releases 页面，不会安装或下载组件。GitHub 的 **Source code** 下载项供开发使用。
