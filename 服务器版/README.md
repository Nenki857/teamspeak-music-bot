# 服务器版

双击 **一键部署.cmd**。等待 5 秒自动部署/更新；按 M 打开管理菜单。已安装的服务器更新当前代码，保留原有数据、公开入口和音频后端，首次安装会准备官网登录浏览器。

首次填写 SSH 地址、端口、已核实的 ED25519 指纹及私钥文件路径。配置只存放在 work/deployment/settings.json，不上传 GitHub；必须先在自己终端核实并信任服务器。

菜单包含：部署/更新、主人控制台、服务状态、重启、固定公网入口、音频检查、切换官方音频、恢复原音频、连接设置和打包。以后更新源代码后继续使用此入口，不需要新增 CMD。

安装和更新需要免密 sudo；首次 TS 预设、网易云登录和第三方许可证仍由你确认。固定入口首次需要放行 TCP 80/443。
